# Linkedin Video

Video promoting Movie Kombat and TMDB API for developers.

## Ideas

- Basic introduction to Movie Kombat
- Show how the app uses different endpoints from the TMDB API
- Make animation showing the flow of data from the API to the app
- Explain how images are rendered using the TMDB API
- Explain other interesting endpoints not used in the app but available in the TMDB API
- Highlight that TMDB has no rate limits and is free to use for developers

## Endpoints used in Movie Kombat

```
https://api.themoviedb.org/3/search/movie
https://api.themoviedb.org/3/discover/movie
https://api.themoviedb.org/3/movie/{movie_id}
https://api.themoviedb.org/3/movie/{movie_id}/watch/providers
```

## Script

### Intro

Tired of netflix doomscrolling? Do you have a huge watchlist but can't decide?

Just let those movies fight into a battle and find out which one is the best!

### Movie Kombat demo

Search for movies, add them from the predefined collections or just browse the most popular movies of your network. 

Once you have your challengers, start the battle and let the movies fight until only one is left standing.

### TMDB API

This app is powered by the TMDB API. An amazing resource to get all the data you need about movies, TV shows and people in the entertainment industry.


**Search movie:** https://api.themoviedb.org/3/search/movie

Search movies by title.

**Discover movie:** https://api.themoviedb.org/3/discover/movie


* Movie details: https://api.themoviedb.org/3/movie/{movie_id}
* Watch providers: https://api.themoviedb.org/3/movie/{movie_id}/watch/providers
